# Apolla Work 性能基准报告

- 日期：2026-08-28
- 模型：mock（零模型延迟）—— 度量平台自身开销，排除 LLM 推理时延
- 运行环境：Darwin 25.6.0 · 10 vCPU · Node v25.9.0
- 任务形态：每任务多步（Write → Bash 真实子进程 → Write → Artifact），auto 模式自动放行

> 口径：mock 模型无网络/推理延迟，因此下列数字反映的是**平台调度 + 工具执行 + 事件下沉 + 进程创建**的开销基线；
> 生产环境单任务时延与吞吐主要由模型 TTFT 与生成速度决定。容器执行器层面的隔离/泄漏指标（PRD T-102）不在本进程内基准范围。
