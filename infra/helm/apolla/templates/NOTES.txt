1. 访问入口
{{- if .Values.ingress.enabled }}
   Ingress 已启用：
     http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}{{ .Values.ingress.path }}
{{- else }}
   未启用 Ingress，可先用端口转发验证：
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "apolla.fullname" . }}-server {{ .Values.server.service.port }}:{{ .Values.server.service.port }}
   然后访问 http://localhost:{{ .Values.server.service.port }}
{{- end }}

2. 查看状态与日志
   kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
   kubectl -n {{ .Release.Namespace }} logs -f deploy/{{ include "apolla.fullname" . }}-server

3. 密钥
{{- if .Values.secrets.existingSecret }}
   使用已有 Secret：{{ .Values.secrets.existingSecret }}（键：apolla-master-key / postgres-password / s3-access-key / s3-secret-key / model-api-key）
{{- else }}
   密钥存放在 Secret：{{ include "apolla.secretName" . }}
   查看主密钥：kubectl -n {{ .Release.Namespace }} get secret {{ include "apolla.secretName" . }} -o jsonpath='{.data.apolla-master-key}' | base64 -d
   注意：升级时请保持 secrets.* 不变（尤其 masterKey），否则已加密数据无法解密。
{{- end }}
