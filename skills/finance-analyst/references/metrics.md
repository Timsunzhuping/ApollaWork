# 财务指标公式手册（finance-analyst 参考）

> 按需 `Read` 本文件查证公式与口径。比率类结果为小数，展示时乘 100 转百分数。
> 单位务必全表一致；区分**合并**与**母公司**口径、**归母**与**全部**净利润。

## 一、三大报表关键科目

### 利润表（Income Statement）
- 营业收入 revenue
- 营业成本 cost_of_sales
- 毛利 gross_profit = 营业收入 − 营业成本
- 营业利润 operating_profit
- 利润总额（税前利润）ebt
- 所得税费用 tax
- 净利润 net_profit
- 归母净利润 net_profit_attributable
- 息税前利润 ebit ≈ 利润总额 + 利息费用（或 营业利润 + 非经常性调整，视口径）
- 利息费用 interest_expense

### 资产负债表（Balance Sheet）
- 资产总计 total_assets
- 负债总计 total_liabilities
- 所有者权益合计 total_equity = 资产总计 − 负债总计
- 归母所有者权益 equity_attributable
- 流动资产 current_assets、流动负债 current_liabilities
- 存货 inventory、应收账款 accounts_receivable、货币资金 cash

### 现金流量表（Cash Flow Statement）
- 经营活动现金流净额 operating_cash_flow
- 投资活动现金流净额、筹资活动现金流净额

> 涉及“平均”口径的周转/回报率，严谨做法用期初期末均值：
> 平均资产 = (期初资产 + 期末资产) / 2。数据只有单期时退化为用期末值，并在结论中注明。

## 二、盈利能力
| 指标 | 公式 | 说明 |
|---|---|---|
| 毛利率 gross_margin | 毛利 / 营业收入 | 越高说明产品/服务附加值越高 |
| 营业利润率 operating_margin | 营业利润 / 营业收入 | 主营盈利能力 |
| 净利率 net_margin | 净利润 / 营业收入 | 最终盈利能力 |
| ROE（净资产收益率）| 归母净利润 / 归母所有者权益 | 股东回报核心指标；可用平均净资产 |
| ROA（总资产收益率）| 净利润 / 总资产 | 资产整体盈利效率；可用平均总资产 |
| ROIC（投入资本回报率）| EBIT×(1−税率) / (有息负债 + 权益) | 衡量资本使用效率（进阶） |

## 三、偿债能力
| 指标 | 公式 | 参考区间 |
|---|---|---|
| 资产负债率 debt_to_asset | 负债总计 / 资产总计 | 视行业；制造业常 40%~60% |
| 流动比率 current_ratio | 流动资产 / 流动负债 | 一般 >1.5~2 较稳健 |
| 速动比率 quick_ratio | (流动资产 − 存货) / 流动负债 | 一般 >1 较稳健 |
| 权益乘数 equity_multiplier | 总资产 / 归母所有者权益 | = 1 / (1 − 资产负债率<归母口径近似>) |
| 利息保障倍数 interest_coverage | EBIT / 利息费用 | 越高偿息能力越强 |

## 四、运营效率（周转）
| 指标 | 公式 | 说明 |
|---|---|---|
| 总资产周转率 asset_turnover | 营业收入 / 总资产 | 每元资产产生的收入 |
| 应收账款周转率 ar_turnover | 营业收入 / 应收账款 | 回款速度；÷365 得回款天数 |
| 存货周转率 inventory_turnover | 营业成本 / 存货 | 备货效率；÷365 得存货天数 |
| 应收账款周转天数 | 365 / 应收账款周转率 | 越短越好 |
| 存货周转天数 | 365 / 存货周转率 | 越短越好 |

## 五、成长性（同比 / 环比 / 复合增速）
- 同比增长率 YoY = (本期 − 去年同期) / |去年同期|
- 环比增长率 QoQ/MoM = (本期 − 上期) / |上期|
- 复合年均增长率 CAGR = (期末值 / 期初值)^(1 / 年数) − 1
- 常用对象：营业收入、归母净利润、经营现金流。
- 注意：基数为负或接近 0 时增长率无意义，应改用绝对额变化说明，并在结论中标注。

## 六、杜邦分析（DuPont）
把 ROE 拆成三块，定位驱动因素：

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/营业收入) × (营业收入/总资产) × (总资产/所有者权益)
```

- **净利率**↑：盈利能力驱动（提价、降本、费用控制）。
- **总资产周转率**↑：运营效率驱动（资产更高效地产生收入）。
- **权益乘数**↑：财务杠杆驱动（举债放大回报，同时放大风险）。

进阶五因素分解：
```
ROE = 税负 × 息税前利润率 × 资产周转率 × 权益乘数 × 利息负担
    = (净利润/税前利润) × (EBIT/营业收入) × (营业收入/总资产)
      × (总资产/权益) × (税前利润/EBIT)
```
分析口径提示：ROE 分子建议用归母净利润、分母用归母权益；做三因素连乘验证时，
若分子改用全部净利润，注意与 ROE 口径的细微差异（`fin_metrics.compute_ratios`
的 `dupont_roe` 用全部净利润连乘，`roe` 用归母口径，二者可能略有出入，属正常）。

## 七、现金质量
| 指标 | 公式 | 说明 |
|---|---|---|
| 净现比 ocf_to_net_profit | 经营活动现金流净额 / 净利润 | >1 说明利润有现金支撑，盈利质量高 |
| 有效税率 effective_tax_rate | 所得税费用 / 利润总额 | 异常偏离法定税率需关注 |

## 八、分析结论写法（建议结构）
1. **总览**：营收/净利规模与同比，一句话定调（增长/承压/扭亏等）。
2. **盈利能力**：毛利率、净利率、ROE 的水平与变动，结合杜邦定位驱动因素。
3. **营运与偿债**：周转天数、资产负债率、流动/速动比率，判断效率与风险。
4. **现金质量**：净现比佐证利润含金量。
5. **风险与展望**：基数效应、单期口径、非经常性损益、行业对比的局限性说明。
