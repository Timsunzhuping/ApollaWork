# 文档翻译

对工作区中的文本/Markdown 文档做中英互译，保持排版与含义准确。

## 步骤

1. 用 Read 读取源文档，判断语言方向（中→英 或 英→中）。二进制文档（docx/pdf）先用 pdf-toolkit / 相关技能取出文本。
2. 逐段翻译，要求：
   - 保留 Markdown 结构（标题层级、列表、表格、代码块不译）。
   - 术语一致：维护一个术语表，同一术语全篇统一；专业名词首次出现给「译名（原文）」。
   - 数字、单位、专有名词、代码、URL 原样保留。
   - 语气与文体贴合原文（正式文件用正式书面语）。
3. 长文档用 Bash 分段处理避免遗漏；翻译完整通读一遍检查连贯性与漏译。

## 产出

写入 `translated.md`（如中译英则 `translated-en.md`），用 Artifact 登记为「译文」。附一个简短术语对照表（原文→译文）说明关键术语的处理。
