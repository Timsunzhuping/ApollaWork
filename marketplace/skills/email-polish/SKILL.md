# 邮件起草与润色

帮助用户把零散要点变成专业、得体的商务邮件。

## 步骤

1. 明确要素：收件人关系（上级/同级/客户/供应商）、目的（通知/请求/致歉/跟进/感谢）、关键信息、期望的下一步。缺失时用 AskUserQuestion 询问一次，不要臆造事实。
2. 生成邮件，结构固定：
   - **主题**：给 2 个可选主题行（简洁、含关键信息）。
   - **称呼**：按关系选择（尊敬的 X / Hi X）。
   - **正文**：开门见山说明目的 → 展开必要信息（可用短列表）→ 明确请求或下一步 → 结尾礼貌收束。
   - **落款**。
3. 语气把控：对外正式、对内简洁；请求类要明确 deadline 与所需支持；致歉类先致歉再给方案。
4. 若用户要中英双语，中文在上、英文在下，术语一致。

## 产出

把最终邮件写入工作区文件 `draft-email.md`（含主题选项 + 正文），并用 Artifact 登记为「邮件草稿」。附一句话说明你做了哪些润色（如"把要点整理为三段，补充了明确的截止时间"）。
